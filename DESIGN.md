# Hardcore Challenge Tracker

The tracker is a crew manifest for a run in the Fog. VT323 carries headings, controls, and the scoreboard, matching the DBD Toolkit. The palette uses charcoal and warm off-white, with amber for active play, muted green for escapes, and rust for eliminations. State is always written out.

The roster takes the widest column, with match logging alongside it on desktop and above it on narrow screens. Lazy-loaded character thumbnails identify both rosters. Character names and monograms remain visible when a portrait is unavailable. Shared views use the same manifest. The OBS layout has a compact, translucent scoreboard designed for compositing over gameplay.

Motion is limited to short control transitions and respects reduced-motion preferences. Outcome feedback stays in the scoreboard, roster, and timeline.
